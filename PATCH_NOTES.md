# Patch notes

## 0.1.3

- Fixed frozen bloom when using a size below the renderer's working range.
- Bloom size now ranges from 3 to 8; older unsafe values are corrected on load.
- VainSabers glow compatibility is automatic while bloom is enabled.

## 0.1.2

- Added a separate Bloom size setting, independent of texture quality.

## 0.1.1

- Reduced the default bloom strength.
- Increased default quality to 512 pixels to reduce coarse sampling.
- Corrected intensity control and made small adjustments visible in the menu.

## 0.1.0

- Initial whole-game bloom with an enable switch, intensity and quality controls.
